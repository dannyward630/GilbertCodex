# File Creation Tools

Prefer typed creation tools over raw writes when they fit the requested artifact.

Before creating files:
- Check for existing files when the name or path may already exist.
- Keep generated content scoped and useful.
- Avoid overwriting unless the user asked for replacement.
- Use batch creation when several related files belong together.

For code files, match the surrounding project style and include only helpful comments.
