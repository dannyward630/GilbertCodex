# License And UI Protection

Gilbert Codex is no longer presented as a plain MIT project. The repository
uses a split license:

- Implementation code and developer documentation are available under the MIT
  License except for Reserved Materials.
- The Gilbert Codex UI, UX visual design, product identity, brand assets,
  screenshots, installer artwork, promotional assets, product look and feel,
  and agent tool system are proprietary and all rights are reserved.

## What Is Allowed

- Study the project architecture and product idea.
- Reuse MIT-licensed implementation techniques that do not copy the Gilbert
  Codex visual design, brand, or agent tool system.
- Build a different agent workspace with its own interface, branding, layout,
  visual system, product identity, and independently designed tool system.
- Contribute fixes and features under the repository's split license.

## What Is Not Allowed

- Copy, clone, or substantially replicate the Gilbert Codex UI.
- Reuse Gilbert Codex logos, icons, installer artwork, screenshots, promo
  assets, or branding without written permission.
- Ship a product that looks confusingly similar to Gilbert Codex.
- Treat UI source files, CSS, screenshots, or visual assets as MIT-licensed
  design templates.
- Copy, reuse, repackage, or externally integrate the Gilbert Codex AI tool
  names, schemas, prompts, tool-call contracts, local action bridge behavior,
  permission flows, connected-tool presets, automation/tool orchestration, or
  visible tool-progress protocols without written permission.
- Use Gilbert Codex AI tools outside authorized Gilbert Codex builds,
  authorized project workflows, or separate written permission from the
  maintainers.

## Protected Material

The protected UI and brand boundary includes the chat workspace, composer,
sidebars, settings surfaces, Apps/Skills/Plugins hub, custom window chrome,
theme system, visual spacing, typography choices, color palettes, motion,
component composition, icon/logo assets, installer art, screenshots, README
artwork, and promotional scenes.

The protected agent tool boundary includes tool definitions, tool schemas,
tool prompts, runtime tool instructions, permission/approval flows,
tool-progress protocols, local computer actions, terminal/file/browser/Git
tool orchestration, connected-app and MCP tool presets, automation tool
behavior, and the app-owned local action bridge.

## Contributor Terms

By submitting a contribution, you agree that your contribution is provided
under the repository license in `LICENSE`. Contributions that add or change UI,
UX, branding, screenshots, installer artwork, promotional material, AI tools,
tool schemas, tool prompts, permission flows, or local action/tool
orchestration are accepted as part of the Reserved Materials unless the
maintainers explicitly mark them otherwise in writing.

## Maintainer Note

This file is a project policy, not legal advice. Before a major public launch,
license dispute, enforcement action, or outside contributor push, have an
attorney review the split license, contribution terms, copyright strategy,
trademark/trade dress posture, and any needed contributor agreement.
