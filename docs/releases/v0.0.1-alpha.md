# Gilbert Codex v0.0.1-alpha

This is the first public alpha release of Gilbert Codex, a local-first desktop agent workspace built with React, TypeScript, Tauri 2, and Rust.

## Download

- Windows x64 installer: `Gilbert-Codex-0.0.1-alpha-x64-setup.exe`
- SHA-256: `6a600699ad25c941c516886651fde4b9c658cedcfb3afb80bab0d2046a9e3568`
- Approximate size: 4.4 MB

This build is currently unsigned. Windows SmartScreen may ask for extra confirmation before installing.

## What Is Included

- Chat-first desktop workspace with local accounts, project grouping, pinned chats, searchable history, markdown rendering, attachments, stop, regenerate, and local persistence.
- Multi-provider model runtime for OpenRouter, OpenAI, Anthropic, Google Gemini, xAI, LM Studio, Ollama, Groq, Mistral, and DeepSeek.
- Thinking controls, planning mode, live model catalogs where available, provider usage tracking, and empty-response retry handling.
- DuckDuckGo-backed web search with source cards and inspector visibility.
- Local computer context with folder selection, file indexing, file search, read, write, delete safety, and duplicate-safe file creation helpers.
- Coding tool pack for typed TXT, Markdown, code, React, HTML, PDF, notes, SQL, React Native screens, tests, API routes, vectors, dependency reports, and codebase health scans.
- GitHub integration path with browser login setup, repository listing, branch and file reads, code search, branch creation, API-backed commits, and draft pull requests.
- Discord slash-command bridge setup/runtime with signed interactions, ngrok-backed public URL discovery, incoming webhook storage, and GitHub-to-Discord event notes.
- Desktop terminal panel, browser preview panel, Toolbox feature toggles, desktop notifications, settings, and visible activity/progress surfaces.
- Tauri CSP and least-privilege notification capabilities for a tighter native shell baseline.

## Getting Started

1. Download the Windows x64 setup executable from the GitHub release.
2. Run the installer and open Gilbert Codex.
3. Create a local account in the desktop app.
4. Add provider keys or local model endpoints in Settings.
5. Optional: configure GitHub OAuth or the Discord bridge from Settings if those integrations are needed.

Provider keys, local endpoints, desktop accounts, GitHub tokens, Discord settings, logs, and workspace data are local user data. They are not bundled in the installer and should not be committed to the repository.

## Alpha Notes

- This is an early alpha intended for testing, collaboration, and feedback.
- The Windows build is not code-signed yet.
- Auto-update support is not enabled yet.
- macOS and Linux installers are not packaged in this release.
- Some tool permissions and native command-layer flows are still being hardened.
- Local secret storage still needs an OS-backed secure-storage pass.
