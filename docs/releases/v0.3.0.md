# Gilbert Codex v0.3.0

Gilbert Codex v0.3.0 is the next major public alpha update. It brings the desktop app closer to a complete local agent workspace: broader tool routing, a stronger model/runtime surface, MCP groundwork, weather and Mapbox settings, PDF/library support, better browser and terminal handling, and another open-source hygiene pass before the update goes public.

## Download

- Windows x64 installer: `Gilbert-Codex-0.3.0-x64-setup.exe`
- SHA-256: publish as `Gilbert-Codex-0.3.0-x64-setup.exe.sha256` on the GitHub release.
- Signed updater signature: `Gilbert-Codex-0.3.0-x64-setup.exe.sig`
- Tauri updater feed: `latest.json`
- Approximate size: publish on the GitHub release asset list after the signed build.

This build is still not code-signed with a Windows Authenticode certificate. Windows SmartScreen may ask for extra confirmation before installing.

macOS and Linux release artifacts are not official yet. The repo has partial source support for both platforms, and contributors with those operating systems are needed to test and complete the port.

## Major Update

- Expanded the local agent runtime with stronger tool-call normalization, schema adapters, project tool metadata, and self-healing support for tool behavior.
- Added MCP-facing app surfaces and services so external tool servers can become part of the desktop workflow.
- Added weather and Mapbox configuration surfaces, weather tool execution, and a weather-radar page path.
- Added PDF/library support and expanded typed file creation flows for generated local artifacts.
- Improved model selection and provider/runtime ergonomics with a dedicated model selector surface and richer model metadata.
- Tightened browser-preview behavior, external-link handoff, local URL handling, and window/runtime client utilities.
- Strengthened terminal session handling, background command attachment, and workspace-aware command execution.
- Added onboarding and utility surfaces to make the public alpha easier for new contributors and testers to understand.

## Open Source Readiness

- Confirmed the local Gilbert Database stays local-only and is not tracked by Git.
- Ignored local database journals, local diagnostic logs, local scan reports, generated build output, dependency folders, and tool caches.
- Kept `.env.example` as the public configuration template while real `.env` files remain ignored.
- Updated release-facing documentation so contributors can see the v0.3.0 target and the local-data boundary.

## Known Limits

- Windows x64 is still the only official packaged target for this release.
- The installer is not code-signed with a Windows Authenticode certificate yet.
- macOS and Linux still need native contributors to validate launch, packaging, shell behavior, and platform-specific fixes.
- Provider keys, GitHub tokens, Discord settings, local accounts, logs, workspace data, local databases, local scan artifacts, release signing credentials, and updater private keys remain local user data and are not bundled.

## Verification

Run the release validation set before tagging:

```powershell
npm.cmd run check
npm.cmd run audit:prod
npm.cmd run app:installer
git diff --check
```

The final GitHub release should include the signed installer, matching `.sig`, `latest.json`, and a `.sha256` checksum generated from the public release asset.
