# Gilbert Codex v0.2.3

Gilbert Codex v0.2.3 is the Terminal Stability Pack: a major alpha bug-fix release for the local terminal, command runner, workspace-aware tool flow, and release-ready desktop polish. The goal is simple: terminal-heavy coding tasks should run more reliably, surface their live state clearly, and recover from failures with better evidence.

## Download

- Windows x64 installer: `Gilbert-Codex-0.2.3-x64-setup.exe`
- SHA-256: published as `Gilbert-Codex-0.2.3-x64-setup.exe.sha256` on the GitHub release.
- Signed updater signature: `Gilbert-Codex-0.2.3-x64-setup.exe.sig`
- Tauri updater feed: `latest.json`
- Approximate size: published on the GitHub release asset list after the signed build.

This build is still not code-signed with a Windows Authenticode certificate. Windows SmartScreen may ask for extra confirmation before installing.

macOS and Linux release artifacts are not official yet. The repo has partial source support for both platforms, and contributors with those operating systems are needed to test and complete the port.

## Terminal Stability Pack

- Added a PowerShell compatibility prelude for terminal sessions and command runs so common inspection helpers like `head`, `tail`, `grep`, `which`, and real `curl.exe` behavior work in the Windows desktop terminal.
- Normalized Windows package-manager shims so `npm`, `npx`, `pnpm`, and `yarn` route to their `.cmd` launchers when PowerShell needs them.
- Increased the terminal command ceiling to 10 minutes for installs, builds, checks, and other longer verification jobs.
- Added a stable buffered command-runner path for quick evidence commands, package lifecycle commands, and Git inspection commands so output arrives cleanly instead of hanging the UI.
- Improved failure recovery hints after build/typecheck/test failures so the agent is nudged toward the first local source error before changing project configuration.
- Added live background command attachment in the terminal dock, including running status, active command display, recent output replay, and safer session ownership cleanup.
- Preserved background terminal sessions when the panel attaches to an existing live command, avoiding accidental kills during UI remounts.
- Added Rust terminal tests for stdout, stderr, exit codes, Windows `cmd /c`, npm shims, PowerShell helper commands, and curl alias handling.

## Runtime And Tool Fixes

- Raised standard and deep-research tool-call budgets while adding safer parallel execution limits for reads, independent mutations, and source-file edits.
- Added approval-resume dedupe so completed tool calls are reused after an approval card instead of being executed twice.
- Added per-pass mutation guards so the app does not apply repeated edits to the same source file in one tool pass.
- Added automatic syntax/build check selection after source edits where the project exposes a useful script or language check.
- Added workspace context snapshots to the agent prompt, including detected project type, package manager, scripts, shell, permission mode, and Git branch state.
- Added Node/npm and Python project recipes so the agent can pick the right package manager, shell style, install command, and verification command earlier.
- Added browser-preview automation availability in the runtime prompt for local desktop verification.
- Removed the unfinished vector tools from the visible Toolbox and runtime tool list until that retrieval surface is ready for users.

## App Polish

- Added safe external link handoff through a Tauri command that only opens `http`, `https`, and `mailto` links.
- Improved local browser-preview probing for CORS and opaque responses so local dev servers are detected more reliably.
- Added pasted-image attachment support in the composer.
- Tightened stop-response handling so the stop button targets the active generation even when the caller does not pass a message id.
- Updated Discord bridge docs to describe the configurable local bridge port instead of implying one fixed port.
- Added a security hardening backlog for OS-backed secrets, Discord/tunnel token storage, and local QA checks.
- Ignored local Claude/Cursor agent settings so machine-specific helper config does not enter the public repo.

## Known Limits

- Windows x64 is still the only official packaged target for this release.
- The installer is not code-signed with a Windows Authenticode certificate yet.
- macOS and Linux still need native contributors to validate launch, packaging, shell behavior, and platform-specific fixes.
- WhatsApp, image generation, video generation, and the model-selector revamp are roadmap items, not shipped features in v0.2.3.
- Provider keys, GitHub tokens, Discord settings, local accounts, logs, workspace data, local databases, release signing credentials, and updater private keys remain local user data and are not bundled.
