# Gilbert Codex v0.5.6

Gilbert Codex v0.5.6 is a focused Windows hotfix for subscription routing, offline dictation, and desktop notifications.

## Release Status

- Version: `0.5.6`
- Tag: `v0.5.6`
- Previous public release: `v0.5.5`
- Primary packaged target: Windows x64
- Release vehicle: GitHub Actions `Release` workflow plus Tauri NSIS installer
- Installer family: `Gilbert-Codex-0.5.6-x64-setup.exe`
- Update feed asset: `latest.json`
- Updater signature asset: `Gilbert-Codex-0.5.6-x64-setup.exe.sig`
- Checksum asset: `Gilbert-Codex-0.5.6-x64-setup.exe.sha256`
- Published SHA-256: pending final release build

## What Changed

- Fixed 9Router subscription OAuth requests that could fail with HTTP 401 before opening the browser sign-in flow.
- Added app-start subscription routing bootstrap so signed-in desktop users install, refresh, and start the local 9Router runtime automatically after install or app update.
- Tightened Free Auto subscription routing so the app repairs the selected local route when possible and keeps the no-auth OpenCode defaults constrained to supported free routes.
- Improved offline dictation release stability by forcing portable Whisper/GGML build settings in local and GitHub Actions release builds.
- Improved dictation transcription quality with a short tail capture, beam-search decoding, and optional dictionary terms from the composer.
- Fixed Windows completion notifications to use a native clickable bridge that focuses the app and routes back to the exact chat.
